# Mis skills de Claude

Cada carpeta es una skill (contiene un `SKILL.md`).

- presupuestos-clientes: baremo, presupuesto y reparto 60/40 de proyectos web
- lanzamiento-web: checklist de publicación de una web
- apex-plsql: código Oracle PL/SQL y APEX con mis convenciones
- resumen-apuntes: resumen de apuntes y fichas para Anki
- test-examenes: exámenes tipo test interactivos
- revision-codigo: revisión de código
- aprende: modo de enseñanza paso a paso
- ingenieria: documentación técnica, incidencias y decisiones de arquitectura
- objetividad-total: respuestas objetivas, sin complacencia
- token-optimizer: respuestas con el mínimo de tokens

Para usarlas en claude.ai: comprime la carpeta de una skill en un zip y súbelo en Customize > Skills.
En Claude Code: copia las carpetas a `~/.claude/skills/`.
